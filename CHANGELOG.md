# Changelog

## v1.1.0

First public Kodiac source release. The preceding source-import history was
reconstructed; see [release provenance](docs/RELEASE.md).

- Package the Rust HTTP server and embedded React 19 catalog as `kodiac`.
- Support original-file ranges, bounded MP4 remux/conversion and fixed-rendition HLS.
- Preserve source identities in a relational movie/show/season/episode catalog.
- Provide account-owned profiles, resume history and optional TMDB enrichment.
- Expose a documented Jellyfin discovery, navigation and PlaybackInfo subset.
- Include persistent browser playback, virtualized catalog rows and runtime settings.
- Publish public Rust API documentation, contributor/security policies and issue forms.
- Distribute the combined work under GPL-3.0-only with inherited notices retained.

Physical client/device validation and reproducible comparative benchmarks remain
outside the release claims. Consult the compatibility guide for supported contracts.
